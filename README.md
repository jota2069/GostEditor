# GostEditor

GostEditor - редактор документов по ГОСТ.

Основная идея проекта - не использовать готовый текстовый редактор, а работать напрямую с моделью документа. Из-за этого форматирование, разметка страниц, сериализация и экспорт реализованы внутри проекта.

Сейчас редактор умеет:

- создавать и редактировать документы;
- работать с заголовками и автоматически собирать содержание;
- вставлять изображения;
- импортировать листинги из исходного кода;
- сохранять документы в формате `.gost`;
- экспортировать документы в DOCX;
- работать со списком литературы;
- отменять и повторять изменения;
- искать текст;
- масштабировать страницы.
